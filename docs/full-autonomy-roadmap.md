## 「转卖赚差价」的完整闭环怎么拼

```
买侧（半自动，付款人工）                卖侧（全自动，开鱼小铺后）
├─ snipe.watch 订阅关键词               ├─ 商品上架（人工一次性，或开鱼小铺后扩展发布 API）
├─ 定时扫描 → snipe_hit 事件            ├─ 询价自动回复（查价技能支撑）
├─ 人工看链接 → 自己拍下付款            ├─ 议价 → floor 判定 → reprice 改价 → 引导拍下
└─ 收货转挂                             ├─ 付款卡片 → 自动发货内容 → 风控闸门 → 确认交易
                                        └─ 每日审计：挂价 vs 中位价 → 调价建议/自动调价
```

利润链路 = snipe 发现低价 → 人工买 → 上架 → robot 全自动卖 → 确认发货 → 审计调价。
其中唯一的人工点是「付款」——这是有意的设计，见 sop/sop-snipe-watch.yaml 的理由。

## 解锁改价（议价自动成交的最后一块）

1. 闲鱼 App / 网页 卖家中心 → 开通**鱼小铺**（可能需实名，一次性人工动作）；
2. 重跑 `uv run --project gate xy-gate capability`，确认 `seller_items` 返回真实商品；
3. `config/robot.yaml` → `reprice.enabled: true` + `mode: live`；
4. 之后 sop-bargain-close 全自动跑：买家还价 ≥ 底价 → 自动改价 → 引导拍下。

## 风险提示（转卖模式额外注意）

- 低买高卖在同一品类高频操作，比单卖自用品更容易触发闲鱼风控/限流；
- 差价品类建议分散关键词、控制上架频率；
- 自动改价有降幅/频次/底价三道闸门，勿盲目放宽（risk.py）。
