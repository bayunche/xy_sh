# 意图分类（auto-reply 前置步骤）

把买家消息归入且仅归入以下一类，输出 `意图` + `置信度(高/中/低)`：

| 意图 | 判定特征 | 处置 |
|---|---|---|
| 代订询价 | 订酒店/代订/入住/几晚/大床房/标间/含早 + 酒店名或日期 | 走 `xianyu-hotel-quote` 技能（优先级仅次于售后纠纷） |
| 询价 | 问价格/在不在/还有吗/什么版本 | 正常回复，必要时查价 |
| 砍价 | 「便宜点」「刀」「包邮呗」「xx 出」 | 按底价策略回复，低于底价转人工 |
| 催发货 | 付款后问发货/单号/怎么还没发 | 安抚 + 告知已发/即将发 |
| 商品咨询 | 问成色/配件/电池/保修/瑕疵 | 如实按商品资料答，不知道就说要回去看实物 |
| 售后纠纷 | 退款/坏了/不对版/投诉/差评 | **零自动处理，转人工** |
| 闲聊 | 表情、问候、与交易无关 | 轻量回应一两句，不纠缠 |

## 判定细则

- 一条消息多个意图 → 取**风险最高**的那个（售后 > 砍价 > 询价 > 咨询 > 催发货 > 闲聊）；
- 买家发图 + 无文字：结合聊天史猜（前文谈价 → 砍价；首条消息 → 询价）；
- 置信度低（拿不准）且第二轮仍低 → 转人工；
- 「这个还能用吗/有锁吗」算商品咨询；「寄来的是坏的」算售后纠纷。
